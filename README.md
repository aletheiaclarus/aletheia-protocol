# The Clarus Protocol

## A verifiable system for citizen voice and public money

**Clarus** is an open proposal for making public institutions more transparent, auditable, and better managed.

The principle is simple:

> **Verify, do not trust.**

Clarus is designed as a public verification layer for government finances, public contracts, public compensation, political promises, and democratic processes.

It does not replace constitutions, courts, legislatures, governments, or electoral authorities. It provides evidence that citizens, journalists, researchers, auditors, courts, and public institutions can independently verify.

### What Clarus aims to make possible

- **Public money:** follow budgets, contracts, payments, and results.
- **Public contracts:** make spending and procurement easier to examine and compare.
- **Public compensation:** provide transparent information about public salaries and compensation.
- **Government finances:** present public finances in a clear, verifiable structure.
- **Promises and performance:** record what public officials promise and what subsequently happens.
- **Voting:** support secure, auditable democratic processes while protecting ballot secrecy.
- **Audit signals:** identify patterns that deserve investigation without treating an automated flag as proof of wrongdoing.

### Core principles

1. **Verify, do not trust.**
2. **Open by default.**
3. **Protect personal privacy.**
4. **Separate evidence from accusations.**
5. **Keep independent audit trails.**
6. **Use open standards and auditable software.**
7. **Do not make voting power dependent on wealth.**
8. **Be honest about technical and institutional limitations.**

Clarus does not claim that technology can eliminate corruption or guarantee perfect government.

It aims to make public decisions and public resources **more visible, more verifiable, and harder to change without leaving evidence**.

## The idea

Public institutions manage resources that belong to the public.

Citizens should therefore have practical tools to answer basic questions:

**Where did the money come from?  
Where did it go?  
What was promised?  
What was delivered?  
Who made the decision?  
Can the record be independently verified?**

Clarus is an attempt to build that verification layer.

## Status

This project is an early public proposal.

The protocol is being developed openly so that its assumptions, limitations, security model, governance, and implementation can be examined and improved by others.

There is no cryptocurrency or financial token associated with Clarus.

There is no requirement to trust the author.

The goal is to build something that can be **checked**.
